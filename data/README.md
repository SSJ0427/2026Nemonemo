# 데이터

| 경로 | git | 내용 |
|---|---|---|
| `golden/` | O | Python·Dart 결과 비교용 합성 이미지와 정답 (`python tools/make_golden.py` 로 생성) |
| `raw/` | X | 테스트 사진 원본 40장 내외. 공유 드라이브에서 받아 여기에 넣는다 |
| `videos/` | X | 실시간 안정화 실험용 짧은 동영상 (`experiments/tracker_video.py`) |
| `labels.json` | O | 테스트 사진별 정답 꼭짓점(좌상·우상·우하·좌하, 원본 픽셀 좌표)과 조건 태그 |

## 촬영 가이드

조건별 성공률을 분석할 수 있도록 다양하게 찍는다. 1인당 10장 내외.

- 배경: 밝은 책상 / 어두운 책상 / 문서와 비슷한 색(흰 책상)
- 조명: 형광등 / 자연광 / 한쪽 그림자 / 역광
- 각도: 거의 정면 / 30° / 45° 이상
- 기타: 손가락이 모서리를 가림, 구겨진 종이, 문서 일부가 화면 밖
